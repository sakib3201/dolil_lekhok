# dolil_lekhok
A software for more productive legal writing

This software is designed to convert handwritten legal documents to digital format from images using tessaract OCR.

## Backend
The backend of the software is built using [FastAPI](https://fastapi.tiangolo.com/). All backend code is located in the `backend` folder.

## Frontend
The frontend of the software is built using [SvelteKit](https://kit.svelte.dev/). All frontend code is located in the `frontend` folder.
